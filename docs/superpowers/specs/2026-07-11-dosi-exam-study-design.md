# 도시계획기사 실기 필답형 기출 학습 웹앱 — 설계

날짜: 2026-07-11
목표: 다다음주 도시계획기사 실기 시험 대비. 기출문제 사진 53장을 텍스트로 추출해, PC·폰에서 타이핑으로 풀고 채점받는 학습 웹앱.

## 개요

- **형태**: 서버 없는 정적 웹앱 (바닐라 HTML/CSS/JS 단일 페이지)
- **배포**: GitHub 레포 → GitHub Pages → 폰·PC 브라우저 접속
- **진행 저장**: localStorage (기기별 저장, 기기 간 동기화 없음 — 허용된 제약)
- **데이터 원천**: `C:\Users\tmddd\Desktop\도시계획기사기출이미지` 사진 53장
  (도시계획기사 실기 필답형 기출문제집, 2018~2021+ 연도·회차별 구성)

## 데이터 구조 (`data/questions.json`)

```json
{
  "id": "2018-2-01",
  "year": 2018,
  "round": "제2회",
  "number": 1,
  "points": 6,
  "type": "essay | blank | calc",
  "question": "문제 전문 (빈칸은 ①, ②, ㉠ 등 원문 표기 유지)",
  "answer": {
    "essay": "모범답안 전문",
    "blanks": ["빈칸1 정답", "빈칸2 정답"],
    "calc": { "value": "25%", "solution": "풀이 과정" }
  },
  "keywords": ["채점 하이라이트용 핵심 키워드"],
  "figure": "images/2018-4-03.jpg (그림 문제만, 원본에서 크롭)"
}
```

- 한 문제에 소문항(가/나/1)/2))이 있으면 소문항 단위로 분리해 각각 1개 문제로 저장
- 그림(지형도 등)이 필요한 문제는 원본 사진에서 그림 영역만 크롭해 `images/`에 저장
- 사진 속 손글씨 필기는 무시하고 인쇄 원문 기준으로 추출

## 채점 방식 (유형별)

| 유형 | 방식 |
|---|---|
| `blank` (빈칸) | 빈칸별 입력 → 정규화 후 비교 (공백 제거, 유사 표기 허용). 부분 점수 표시 |
| `calc` (계산) | 숫자 답 비교 (단위·% 허용 오차 처리) → 정답 후 풀이 과정 공개 |
| `essay` (서술) | 입력 답과 모범답안 나란히 표시 + 모범답안의 핵심 키워드가 입력에 포함되면 하이라이트 → 최종 O/X는 사용자가 확정 |

채점 결과는 문제별 이력(`correct`/`wrong` 횟수, 마지막 입력 답)으로 localStorage에 저장.

## 화면 구성 (단일 페이지, 3개 뷰)

1. **홈**: 회차별 선택 목록(문제 수·정답률 표시) / 전체 랜덤 풀기 / 오답노트 / 전체 진행률
2. **풀이**: 문제 표시 → 답 타이핑(빈칸은 칸별 입력, 서술은 textarea) → 채점 → 정답·풀이 확인 → 다음
3. **오답노트**: 틀린 문제만 모아 반복 출제, 맞히면 오답노트에서 자동 제거

모바일 우선 반응형 (폰 화면 기준 레이아웃, PC에서는 가운데 정렬 max-width).

## 추출 파이프라인 (1회성 작업)

1. 사진 53장을 Claude 비전으로 판독 → 문제·정답·유형·회차 추출
2. 병렬 서브에이전트로 분담 (사진 묶음별), 결과를 `questions.json`으로 병합
3. 검수 패스: 회차 누락·문제번호 중복·정답 누락 체크
4. 그림 문제는 원본에서 크롭해 `images/` 저장
